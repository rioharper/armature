# Context

Glossary for the Armature plugin itself (not for user projects — their glossary lives in their own `CONTEXT.md`, alongside `docs/adr/`).

## Terms

- **Stage**: one step of the per-project pipeline (pitch → spec → plan → derive → CAD → build), recorded as the `Stage:` line in a user project's `CLAUDE.md`. A stage spans as many sessions as its plan's leaves need; each session resumes from the repo alone.
- **Session**: one agent context, roughly 100k tokens before output degrades. The unit of a plan's leaf task and of a wayfinder ticket; one session ends in one commit.
- **Leaf**: a plan task sized to one session, living as a `plan:leaf` issue under its phase. Its T-id is **permanent** — assigned once, never renumbered, so an insertion becomes `T3.2c` — and rides as the issue title's prefix, while the issue number carries the machine identity. Parent tasks have no issue of their own: a dependency that named one resolves to its last leaf when the issues are cut. _Avoid_: subtask, step, ticket — a **ticket** resolves a decision under fog; a leaf executes known work under a stage.
- **Effort**: a unit of work too big for one agent session, coordinated across sessions by a wayfinder map. An effort overlays the pipeline; it is not a stage and never moves the `Stage:` line.
- **Map**: the canonical artifact of an effort — destination, notes, decisions index, and fog — with decision tickets as children. Lives on the project's issue tracker.
- **Ticket**: a child of a map, one decision sized to one session, living as an issue labelled `wayfinder:<type>`. Its body is a *question*; its answer is recorded on resolution, never in the body. Shares the tracker and the claim-by-assignee rule with a **leaf** and is not one: a ticket decides under fog, a leaf executes known work whose `Done when` was fixed at planning time. _Avoid_: leaf, task, issue — `issue` is the storage, not the kind.
- **Plan index**: the `plan:index` issue holding everything in a plan that is not a task — scope against hours, machine split, Must satisfiability, CAD process, risks and their hooks, and the `Glossary: see CONTEXT.md` pointer. The plan's counterpart to a **map**: an index, not a store. _Avoid_: plan.md, plan document, the plan file.
- **Draft**: `docs/02-plan/draft.md`, the planning interview's round-by-round checkpoint — gitignored, resumed from on re-invocation, deleted the moment the issues are cut. Explicitly *not* the plan: a draft left on disk is an abandoned interview, not an artifact. _Avoid_: plan, working plan, plan.md.
- **Overlay**: the relationship between wayfinding and the pipeline: stages stay intact and become the means of resolving a map's tickets, rather than being absorbed or wrapped.
- **Staging file**: an agent run's record, written as it goes, waiting to be merged into a shared artifact and deleted once it is. A named-part librarian run stages the rows and cached files it found for `docs/datasheets/index.md`; one pass of a split red-team review stages its findings for the merged report. The librarian calls its own its **run file**. A staging file left behind is an unmerged run. _Avoid_: report, scratch file, index-staging, ledger — the **ledger** is the project's `ledger.toml`.
- **Survey file**: the permanent record of a librarian run that canvassed a slice of a field rather than a named part, `docs/datasheets/<task>-<subject>-<slice>.md`. It is that run's record and outlives its merge, so a survey that confirms no part still leaves its findings. _Avoid_: report, vendor doc, staging file.
- **Environment record**: what the machines a project is built on actually have installed — the project's `docs/environment.md`, one dated section per machine, written only by a run of the plugin's `scripts/env-probe.sh` and never by hand. An absence in it is planning input rather than an error: **init** reports one, **armature-plan** turns one the plan depends on into Phase 0 work with hours against it. _Avoid_: environment check, machine notes, probe output.
- **Truth model**: an independent simulator model of a mechanism — MuJoCo, compiled by the **engine** from the project's **mechanism description** in full, with none of the derivation's **reductions** — that every static, stiffness, modal and torque claim is checked against at randomly sampled configurations. Independence is the whole of it: a check of a model against itself cannot see a wrong assumption, because the assumption sits on both sides. The description is shared, so an error in it is common-mode and has checks of its own; the assumptions are not. Owned by **armature-derive**, built at Milestone 0, and re-run by the red team. _Avoid_: digital twin, sim, reference model — a **digital twin** tracks a machine that exists, a project's **sim** is a consumer of the truth model, and "reference model" says nothing about independence.
- **Mechanism description**: a project's mechanism written down once, as `mechanism(p)` in `analysis/model/mechanism.py`: bodies, joints, sites, cables, loops, contacts and actuators, every number in the base frame at the **home posture**. The truth model is compiled from it and the derivation reads its frames from it. Coarse while a part is unknown, refined at derive, its bodies replaced by measured ones at CAD. _Avoid_: DH table, URDF, model, parameter block — the parameter block, `params.py`, holds the structure around the **ledger**'s values the description reads, not the geometry.
- **Home posture**: the one posture at which a mechanism description writes every number, every loop closed: a joint as an axis direction and a point on it, a COM, site or cable end as a position, an inertia in base axes. Each joint reads its declared home value there, zero unless it says otherwise. _Avoid_: zero configuration, q = 0, rest pose — a joint's home value need not be zero, and the machine need not rest there.
- **Reduction**: one simplification a derivation makes, declared by name against the mechanism description — `lock`, `couple`, `planar`, `lump` or `rigid` — and carrying the number of the assumption in `00_setup.md` it implements. Sized by its release, never argued. _Avoid_: simplification, approximation, gear reduction — the assumption is the sentence in `00_setup.md`; the reduction is its declaration, and a gearbox's is a **gear ratio**.
- **Variant**: the mechanism description with a named set of reductions applied, owned by the derivation; a milestone names the variant it reads. The truth model is never a variant: it always compiles the full description. _Avoid_: simplified model, reduced model, derivation model.
- **Engine**: the plugin's `engine/` package, imported as `armature`, holding the description's elements, its compiler, the truth model's queries, the reductions, the symbolic view and the sampler. A project pins it rather than copying it, so a fix reaches the project as a version bump. _Avoid_: truth package, library, the armature package — **Armature** is the plugin, and the truth package was the per-project copy the engine replaced.
- **Golden mechanism**: a mechanism the plugin tests itself on, with an answer known independently of the engine — a closed form, or an independent computation — and a planted **trap**. There are five: the 2R arm, a cable platform, a five-bar leg on a wheel, a balanced parallelogram arm, and a mass on a spring and on a cable. _Avoid_: fixture — pytest's word for setup code; the `test_fixture_*.py` filenames predate the term.
- **Trap**: the plausible wrong answer a **golden mechanism** is built to catch — a locked elbow, a level platform, first contact checked at one wheel angle. A golden mechanism passes only if the trap is caught, not merely if the right answer appears.
- **Verb matrix**: every **golden mechanism**, and the five-bar leg without its wheel, against every **engine** verb, each cell ending in one of three states: a known answer; covered elsewhere, naming the cell that checks the same code path, where nothing in that path depends on this mechanism's shape; or not applicable, where the verb has no meaning on the mechanism. A cell checked only against the engine itself is none of the three. _Avoid_: coverage matrix — **coverage** is a share of a search space.
- **Eval case**: one `claude plugin eval` case that runs an agent with the plugin against a **golden mechanism**. It measures the agent, where the engine's pytest measures the engine. _Avoid_: test, fixture.
- **Bait**: the assumption an **eval case**'s brief states outright, as if the user wrote it, that invites its **trap** — "the platform stays level", "check first contact at α = 0". The case is caught only if the agent rejects or sizes the bait, so stating it outright ensures the check is exercised. _Avoid_: hint, trap — the trap is the wrong answer; the bait is the sentence that invites it.
- **Unstated variant**: an **eval case**, `<case>-unstated`, that is another case with its **bait** taken out of the brief's numbered assumptions and left implied by the spec's prose. It keeps the case's answer, **window** and **trap**, so it measures whether the agent finds the assumption, where the stated case measures only whether it rejects one it was shown. A red-team variant's derivation uses the bait without numbering it too.
- **Catch rate**: the share of an **eval case**'s runs with the plugin in which the **trap** was caught — the right answer stated and the **bait** rejected or sized, both at once. It is the case's score; a run that gets one of the two is not half caught, and a run that read the answers is not caught. _Avoid_: pass rate, score — `claude plugin eval`'s score averages its graders, so it credits half a catch.
- **Window**: the range around a **golden mechanism**'s known answer that an **eval case** accepts, ±2% unless the case says otherwise; the **bait**'s answer must fall outside it. _Avoid_: band — a **band** is a parameter's design range — and tolerance.
- **Margin**: slack against a limit — available minus required, the limit's derating already applied — so zero or more passes. A budget row's margin is one number; a derivation's is declared over a **search space**, and its worst is searched for by the **engine**, never read at a point somebody picked. _Avoid_: factor of safety, headroom — a factor of safety is one derating inside the limit.
- **Search space**: the set a margin is claimed over, as named axes — posture, load case and sign, load direction, each **band**, any other range — so every one is a dimension of the same search rather than a separate habit. _Avoid_: envelope, workspace, sweep — the envelope and the intended workspace are sets of postures, which a space's posture axis may range over.
- **Ledger**: a project's one file of input numbers, `ledger.toml` at its root (ADR 0010): the mechanism's and the drive's parameters, their bands, the requirements' thresholds, the budgets, and the facts a decision reads off a part's datasheet, each written once. A derived number, such as a total, a margin or a slack, is never in it. _Avoid_: parameter file, params.toml, run file — the librarian's per-run record is a **staging file**.
- **Entry**: one number in the **ledger**, named `<section>.<name>`: an SI value with its unit, a **source kind**, a status, and a **band** where one is granted, or an `of` that reads another entry in place of a value of its own. Its status is `candidate` until the user confirms it, and a candidate carries no decision. _Avoid_: row, parameter, constant — a row belongs to a **view** or the datasheet index.
- **Source kind**: where an entry's number came from, one of six: `chosen`, `standard`, `estimate`, `datasheet`, `cad` or `measured`, each with the citation it requires. Trust rises estimate → datasheet → cad → measured, and chosen and standard sit off that ladder. Separate from status, which says whether the user has confirmed it. _Avoid_: provenance tag, Confirmed / TBD / Assumed, guess / model, CANDIDATE — the four vocabularies it replaced.
- **As written** (`as_written`): an entry's quantity exactly as its source printed it, unit included, "88.4 V/krpm", kept beside the SI value so that the one unit conversion is checked. The datasheet's basis, rms or peak and line or phase, is not part of it. _Avoid_: raw value, original units.
- **View**: a whole table in a project's markdown that is generated from the **ledger** between `<!-- ledger:<view> -->` markers: a budget, the BOM, the spec's requirements, `CONTEXT.md`'s symbols. It changes only through its entries, and a row's prose is its entry's note. _Avoid_: generated file, report, rendered doc — a view is a section of a hand-written document.
- **Band**: the [low, high] a design grants one entry, around its nominal, declared once on its **ledger** entry and an axis of every margin the entry moves. An estimate always carries one. _Avoid_: tolerance alone, range — a joint's range is its travel.
- **Coverage**: the share of a search space, by volume, where a margin passes: how thin it is, never whether it passes, which only its worst says. _Avoid_: pass rate, yield — a yield is a share of parts built, not of a space.
- **UNCHECKED**: a margin whose data is missing — a winding with no thermal RC and no continuous rating, a duty with no written mission. Its row names what is missing and fails the run unless argued exempt (armature-derive's `derivation-standards.md`, *Actuators and the bus*). _Avoid_: skipped, n/a — n/a is the truth gate's verdict on a directory with no mechanism; UNCHECKED is a failure.
- **Corner sweep**: the corners of a search's **band** axes, which every search evaluates, so a margin is stated at its worst tolerance corner rather than at nominal alone. Worst case over *tolerance*, inside the same search as worst case over *workspace*, not a run of its own. Owned by **armature-derive**; a release gate cites it. _Avoid_: tolerance stack-up — that is one fit's accumulation across an assembly, an **armature-cad** check.
- **Mission**: what a mechanism is asked to do, written as a file the way a spec's §6.4 states it: named segments run in order — **moves**, **holds**, **events** and the escape hatch, a followed q(t) — plus a **duty**. Actuators and the bus are sized from missions (ADR 0006), never from a named static case alone. A mission is written (run as it stands) or searched (`mission(point)`, its free choices axes of a search space). _Avoid_: motion profile, trajectory, load case — a profile is one move's, and a load case is a point on a margin's axis.
- **Move**: a mission segment from rest to rest, from a start to an end or along a direction for a distance, profiled by ruckig under velocity, acceleration and jerk limits stated on each coordinate or along the path. _Avoid_: stroke, trajectory.
- **Hold**: a mission segment keeping a posture for a duration under loads. _Avoid_: dwell, static case — a static case is a margin's, with no duration.
- **Event**: a mission segment forward-simulated rather than prescribed, from a state or partway through the segment before it: each motor coasting, shorted, flux-braking or following a torque profile, with the bus stepped alongside. An e-stop, a power loss, a touchdown. _Avoid_: fault, transient.
- **Duty**: the period a written mission repeats on and the session it repeats for, over which the duty margins integrate winding temperature, RMS current and brake power. _Avoid_: duty cycle as a percentage — the engine integrates the mission, not an on-fraction.
- **Trace**: a mission sampled at a rate — 200 Hz in a search, 1 kHz at the confirmation — into each actuator's motor-side torque and speed, with the **rotor's share**, J_m·ω̇_m, split out so gearbox efficiency applies only to the load across the gear. _Avoid_: log, recording — a trace is computed, not measured.
- **Drive**: a project's actuators' electrical half, `drive(p)` in `analysis/model/drive.py`: each motor, driver and gearbox, every constant with its basis, and the **bus** they share. Its margins are `DRIVE_MARGINS`. _Avoid_: powertrain, drivetrain — a drivetrain is mechanical.
- **Bus**: the one DC bus a drive's actuators share: a source that can or cannot sink, or none (a pack unmated), a capacitance band, an optional brake resistor, each driver's flux brake, a constant hotel load, and the voltage ratings of the parts on it that no driver carries. Its voltage is integrated over a trace, and every **clamp** holds it. _Avoid_: rail, supply — a rail is one regulated voltage, and the source is the thing behind the bus.
- **Trip**: the bus voltage at which a driver (its `max_voltage`) or the source (its `overvoltage`) switches itself off, latched for the rest of the mission: a tripped driver's motor coasts, and a tripped source neither sources nor sinks. A part's rating in `Bus(ratings=...)` joins the trips the peak voltage is held under, but switches nothing off. _Avoid_: cutoff, fault — a fault is any of the driver's protections, and a trip is the one the bus voltage sets.
- **Clamp**: anything that holds the DC bus at a voltage: the source at its own voltage (a floor, and a ceiling too if it sinks), a brake resistor above its threshold, a flux brake above its onset. At its level it gives or takes whatever holds V there, up to its capacity, and past that V moves on. _Avoid_: limiter, regulator — a clamp has a capacity, and past it the bus is free.
- **Stand-in**: a catalogue part, or a combination of catalogue parts, close enough to bench-test a long-lead part's function with and never close enough to ship. A schedule hedge that takes bring-up off the long-lead part's critical path, not a substitute for it. _Avoid_: substitute, placeholder, alternate.
- **Reserve**: budget headroom held back for a named future change, carried as a line item nothing debits directly — its current estimate is the ceiling minus every other line's, so a debit elsewhere debits it. Its budget is what a Must requirement demands, so a negative margin is a **breach**: a failed REQ in the row and in `traceability.md`, not a tight margin. _Avoid_: margin, contingency, slack — margin is any row's remaining slack; a reserve is the row that holds it.
- **Executor**: who resolves a ticket or task — a stage skill (`armature-derive`, `armature-cad`, `armature-test`, `armature-bringup`), an agent (inventor / librarian / red-team), or the user; a task a skill drafts and the user executes names both, `armature-bringup + user`. The table lives in **armature-plan** §3, and the tracker carries it as the `executor:*` label namespace — cross-cutting, so a wayfinder ticket wears one as readily as a plan leaf, and `gh issue list --label executor:armature-librarian` is what lets a runner batch work by who does it. Ticket *types* (research / prototype / grilling / task) say what kind of question it is; the executor says who works it. Agents are executors, never ticket types.
- **Agent tier**: which model an agent runs on — pinned in its `agents/*.md` frontmatter as the default, overridable upward at dispatch for an unusually hard run. The librarian and the inventor are pinned to `sonnet`; the red-team inherits whatever the session is on, because a missed finding costs CAD hours and purchases. Policy lives in `references/subagent-dispatch.md`. _Avoid_: model — in this repo a *model* is the SymPy/SciPy model, a CAD model, an OTS vendor model, or the MuJoCo truth model, never the LLM.
- **Link**: a data path between two compute units, named in the spec's §8.2 and carrying a rate and latency budget plus a seam-level verification (`unit` / `sim` / `bench`). Live traffic — a file crossing between units is a **data artifact** instead, with a schema rather than a budget. _Avoid_: interface — §7's Interfaces column is mechanical and electrical, so a protocol named there is a link written in the wrong section.
- **Machine split**: the machines a project is *built* on and which leaf runs on each — the `## Machine split` section of the **plan index**, the superset of the spec's §8.1 runtime hosts, adding the development machines that never ship. It exists for the case where one machine cannot do another's work; a role with no dated section in the **environment record** is unprobed, and probing it is Phase 0 work. _Avoid_: build machine, dev box, workstation.
- **Milestone module**: the Python that accompanies a derivation milestone note under `analysis/model/` — one `.py`, or a package with one submodule per section of the note — mirroring the note's equations and names. Distinct from the note itself, which carries the argument; the module carries the computation. A plan task's module is laid out the same way against its report. _Avoid_: milestone (the note, the module, and the branch together), model file.
- **Checks module**: the sibling `<module>_checks.py` holding a module's self-tests, one file over from what it checks, discovered through that module by name. Never collected by pytest on its own; `test_derivation.py` is the one bridge. _Avoid_: test file — that is pytest's `test_*.py`.
- **Runtime host**: hardware the robot runs on in the field — flight controller, companion computer, ground station — the `Runtime host` column of the spec's §8.1. _Avoid_: machine — **armature-plan**'s machine split is a superset, adding the development machines that never ship (sim host, GPU box, bench laptop).
